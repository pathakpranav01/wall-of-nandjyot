# Wall of Nandjyot — V8

Open `index.html` in a browser.

V8 changes:
- Fixed the wide-screen portrait double-frame effect by making portrait mounts hug the artwork instead of filling the whole grid cell.
- Removed the secondary image shadow that could read as an inner tile.
- Landscape works retain the same single gallery mount and full-row presentation.
- Category filtering is unchanged and remains working as in V7.
- Poetry / कविता shows only **तेजाचे अभय**.
- Photography / छायाचित्रण shows the other three works.
- All / सर्व shows all artwork.
- Responsive desktop, tablet and mobile behaviour is retained.
